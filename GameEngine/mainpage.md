# Zappy GameEngine

Welcome to the documentation for the Zappy project's game engine.

## Overview

This module contains the graphical interface, 2D/3D rendering, window management, networking, and gameplay logic associated with the graphics client.

## Main Modules

- Core and main loop
- Window and event handling
- User interface and menus
- 3D rendering and map management
- Player and asset management
- Network communication with the server
